## What do we want the project to be

We want this project to be an app that assists users (Typically geared towards college students) with budgeting concerns, managing their savings, financial questions, stock advice, etc. We want the main menu to be able to display bank info (Checking acct, savings acct, spending analysis, and recent purchases). On the menu, they can click each of the accounts to view all purchase history. To the left of the main page, there will be a little goldfish that can be clicked, that will provide an AI chatbot feature using an elevenlabs voice. When the users click the goldfish, a chat window will pop up on the side of the main window, allowing for users to interact with the chatbot for advice. TEST
